AngularJS
---------

AngularJS is an Open Source JavaScript framework. It is used in Single Page Application (SPA) projects. It extends HTML DOM with additional attributes 
and makes it more responsive to user actions. AngularJS uses MVC (model-view-controller) architecture, data-binding, client side templates and dependency injection 
to create a much needed structure for building webapps. 
  It is a library written in JavaScript. AngularJS is distributed as a JavaScript file, and can be added to a web page with a script tag:


AngularJS extends HTML attributes with Directives, and binds data to HTML with Expressions.
