
Database Questions

1) What is a primary key in the context of databases, and what is its significance?

  Ans : A primary key in the context of databases is a column (or a set of columns) that uniquely identifies each record in a table. It ensures that
  no two rows in the table have the same value for the primary key, maintaining uniqueness and data integrity.
  Significance of a Primary Key:
  a)Uniqueness – Ensures that each record can be uniquely identified.
  b)Non-nullability – Primary key values cannot be NULL, ensuring every record has a valid identifier.
  c)Indexing – Most database systems automatically create an index on the primary key for faster lookups.
  d)Referential Integrity – Other tables can reference the primary key using foreign keys, maintaining data consistency.
  e)Prevention of Duplicate Records – Helps avoid unintentional duplication of data.
